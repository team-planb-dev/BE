# Phase 5A 트랜잭션 분리 근거

- **경계:** `TransactionTemplate.execute`는 콜백을 트랜잭션에서 실행하고 정상 반환 시 `commit`, `RuntimeException`/`Error` 발생 시 `rollback` 후 예외를 다시 던진다. `status.setRollbackOnly()`로 정상 반환 시에도 롤백을 요청할 수 있다. 기본 전파는 `REQUIRED`이므로 기존 트랜잭션이 있으면 참여한다. 현재 `add-with-recommend` 컨트롤러와 `makeTravelOptionsAndRecommend`에는 외부 `@Transactional`이 없어, 조회 콜백 → AI 호출 → 저장 콜백 순서로 별도 트랜잭션이 성립한다. [Spring 프로그램 방식 트랜잭션](https://docs.spring.io/spring-framework/reference/data-access/transaction/programmatic.html), 설치된 `spring-tx-7.0.9-sources.jar`의 `TransactionTemplate.java`·`DefaultTransactionDefinition.java`, `src/main/java/com/planb/domain/travel/controller/TravelController.java`, `src/main/java/com/planb/domain/travel/facade/TravelFacade.java`.
- **Boot 기본 빈:** 이 프로젝트의 Boot 4.0.2는 `PlatformTransactionManager` 후보가 하나이고 `TransactionOperations` 빈이 없을 때 기본 `TransactionTemplate` 빈을 만든다. 기본 빈 하나를 주입해 `setReadOnly(true)`로 변경하면 공유 설정을 바꾸므로, `TravelTransactionService`가 주입받은 manager로 조회·저장용 템플릿을 각각 생성한다. Facade는 manager나 template을 직접 의존하지 않는다. [Spring `TransactionTemplate` 문서](https://docs.spring.io/spring-framework/reference/data-access/transaction/programmatic.html), 설치된 `spring-boot-transaction-4.0.2-sources.jar`의 `org/springframework/boot/transaction/autoconfigure/TransactionAutoConfiguration.java`.
- **JPA 읽기 전용:** `readOnly`는 쓰기 금지 검사가 아닌 성능 힌트다. Hibernate 사용 시 Spring은 flush mode를 `MANUAL`로 바꾸고 트랜잭션 로컬 세션을 기본 읽기 전용으로 설정한다. 따라서 조회 콜백에서 관리 엔티티를 변경해 저장될 것이라 가정하면 안 된다. [Spring Data JPA 트랜잭션](https://docs.spring.io/spring-data/jpa/reference/jpa/transactions.html), 설치된 `spring-orm-7.0.9-sources.jar`의 `org/springframework/orm/jpa/vendor/HibernateJpaDialect.java`.
- **지연 로딩:** 닫힌 세션 밖에서 초기화되지 않은 프록시/컬렉션에 접근하면 `LazyInitializationException`이 발생한다. 현재 `buildHealthContexts`는 조회 콜백 안에서 `TravelHealthContext`를 값으로 만들고 복약 규칙 컬렉션까지 순회한다. AI 단계에는 엔티티 대신 완성된 컨텍스트가 전달된다. 저장 단계는 건강 엔티티를 새 트랜잭션에서 다시 조회한다. [Hibernate `LazyInitializationException`](https://docs.jboss.org/hibernate/orm/7.0/javadocs/org/hibernate/LazyInitializationException.html), `src/main/java/com/planb/ai/context/TravelHealthContext.java`, `src/main/java/com/planb/domain/travel/facade/TravelFacade.java`.
- **실패 의미:** AI 호출이 실패하면 저장 콜백은 실행되지 않는다. 저장 콜백에서 `BaseException`을 포함한 런타임 예외가 발생하면 그 콜백의 DB 작업은 롤백된다. 첫 조회 트랜잭션은 이미 끝났으므로 두 단계가 하나의 원자적 트랜잭션은 아니다. `src/main/java/com/planb/global/config/exception/domain/BaseException.java`, `src/main/java/com/planb/domain/travel/facade/TravelFacade.java`, 설치된 `spring-tx-7.0.9-sources.jar`의 `TransactionTemplate.java`.
