## 3. 호출 순서와 책임

`PlanService.finishPlan` 순서:

1. `fillMissingTravelMinutes`: 이동시간 확정
2. `validateTravelMinutes`
3. `ScheduleNormalizer.normalizeScheduleTimes`: 시작·종료 시각 확정
4. `refillMissingMeals`(`MissingSlotCompleter`): 누락 식사 보충 후 이동시간 재계산·정규화 재실행. 보충된 점심도 최종 시각은 정규화 결과임
5. `validateTravelMinutes`, `validateMealSlots`: 필수 식사 존재 검증
6. 영양 enrichment
7. `ScheduleNormalizer.ensureMedicationSchedules`: 최종 식사 시각 기준 복약 생성
8. `applyDeterministicTags`: `MEAL_TIME_APPLIED`는 `mealTimeSatisfied` 결과로 부여

`normalizeScheduleTimes`의 식사 규칙:

- 시작 시각은 `직전 장소 종료 + 이동시간`보다 이를 수 없음(물리 제약 우선)
- 식사는 설정 시각 ±30분 범위 안으로 clamp함. 여러 동행인은 범위의 교집합을 씀
- 이동 때문에 상한을 넘으면 `tryShiftPreviousPlaces`가 **직전 식사 이후의 장소들만** 같은 분만큼 앞당김
  - 조건: 첫 장소가 `직전 식사 종료 + 그 장소 이동시간`보다 이르지 않을 것
  - 상한을 완전히 맞출 수 없으면 아무것도 옮기지 않음(부분 이동 없음)
- 직전 식사 자체는 옮기지 않음
- 이동은 직전 식사 뒤 첫 장소의 여유만큼으로 제한된 균일 이동임. 장소 사이 여유는 압축하지 않음

복약은 정규화가 끝난 최종 식사 시각을 기준으로 계산함. 6건 중 4건은 `점심 종료 + 30분`임(예: 서울 2회차 1일차 14:28 종료 → 14:58 복약).
2건은 `점심 종료 + 30분`이 다음 장소 안에 들어가 `moveOutOfPlaceSlots`가 그 장소 종료로 옮겼음.
- 서울 3회차 2일차: 점심 종료 13:47, 복약 15:05(점심 종료 후 78분)
- 부산 3회차 1일차: 점심 종료 13:45, 복약 15:01(점심 종료 후 76분)
