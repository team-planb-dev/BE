작성일: 2026-10-10 · 관련 #172·#173

## 현재 판정

Part 2의 후속 채택 기준은 일정 품질과 실패 복구 안정성. 지연·token·LLM 왕복 수는 보조 지표. 일정 생성 시간이 몇 초 늘었다는 사실만으로 UX 악화 또는 실험 실패를 단정하지 않음. Part 1의 트랜잭션·요청 동시성 최적화 결과와 AI의 선택 품질은 구분.

현재 운영 기준은 P2-4A. 이번 작업은 결과 문서의 dev 병합만 진행하며 main 동기화 없음. P2-4B·P2-4C 구현·회귀·실제 측정은 완료했으나 품질 문제 미해결. 문서 병합과 draft 실험 코드 보존은 운영 채택이나 품질 해결 선언이 아님.

## 실제 결과와 해결되지 않은 품질

4지역×3회, 모델 `gpt-5.6-terra`, reasoning `none`, 생성만 실행. B와 C는 모두 P2-4A와 비교한 별도 실험. 다른 날짜의 소표본이며 인과 확정 근거로 사용하지 않음.

| 지표 | P2-4A | P2-4B | P2-4C |
|---|---:|---:|---:|
| 생성 성공 | 12/12 | 9/12 | 11/12 |
| 지정 장소 포함 | 12/12 | 9/12 | 11/12 |
| 날짜 간 장소 중복 | 0 | 0 | 0 |
| 알레르기 키워드 추정 적중 | 0 | 1 | 1 |
| 확인된 메뉴 출처 일치 | 72/72 | 54/54 | 66/66 |
| 전체 시도 모델 호출 | 61 | 111 | 60 |
| 재선택 단계 실행 | 1 | 13 | 6 |
| 성공 시간 중앙값(보조) | 19.986초 | 27.194초 | 23.889초 |
| 성공 token 중앙값(보조) | 47,916.5 | 22,342 | 35,232 |

- B: 부산 3회 모두 재선택 메뉴 원본 불일치로 저장 거부. 준비 후보·메뉴·식사 자격 중 어느 조건의 실패인지는 현재 메시지만으로 미확정. CAFE_REST 0개로 기존 감시 기준도 초과.
- C: 경주 2회차 이동시간 검증 실패. 정확한 구간·좌표·경로 응답 원인은 미확정. 부산 해물 메뉴가 알레르기 키워드에 적중.
- 알레르기 키워드는 음식점명·메뉴 문자열 기반 proxy. 실제 성분 안전성 증명이 아니며 오탐·미탐 가능성 포함. 과거 적중을 임의 삭제하거나 검증을 완화하지 않음.
- 정상 요청의 장소·메뉴 검증 통과만으로 여행 경험 전체의 품질을 평가한 것으로 주장하지 않음. HIGH 메뉴 비율·영업시간 지표는 기준 미측정.
- JUnit 성공은 관찰 실행기 완료. 실제 일정 생성 성공과 별도 판정.
