## 결과와 증명 범위

생성·슬롯 재선택·Java 식사 보충의 음식점 메뉴 출처 계약을 같은 요청 컨텍스트로 정렬. 후보의 장소 identity 검증과 별개로 TourAPI 상세의 contentid·contenttypeid·성공 코드 및 실제 메뉴 목록을 검사.

무료 테스트는 조회 원본과 선택 값의 관계를 검증하는 증거. 별도 승인한 실제 생성 12회는 10/12 통과, 경주 2회 메뉴 출처 검증 거부, 알레르기 키워드 proxy 1건. 이번 배치의 품질 gate 미충족·미채택. Draft PR #178 유지, dev 미병합·main 동기화 제외.

## 한계와 다음 순서

메뉴 목록의 원문 일치는 실제 재료·알레르기 안전성과 현재 영업을 증명하지 않음. 이번 실제 생성에서 원문 선택 계약에 의한 거부 2건 관측. 정확한 선택 메뉴·상세 원문이 raw에 없어 과도한 거부인지 판정 보류. 동시 요청은 컨텍스트별로 격리되며 동일 컨텍스트 안의 병렬 상세 조회 coalescing은 이번 범위 밖.

후속 2단계는 실패 종류별 복구와 정상 슬롯 보존을 확인하는 작업. 기존 PlanService 슬롯 재선택을 먼저 조사하고 재시도 예산 증가 없이 실제 결함을 구분. 3단계 필수 일정 골격과 4단계 판단 의존 분리는 앞선 실패 증거를 확인한 뒤 도입 여부 결정.

### 실패와 안전성 관찰

지역별 통과: 서울 3/3, 부산 3/3, 강릉 3/3, 경주 1/3. 경주 repeat 2·3은 `AI.EXCEPTION.AI_RESPONSE_REJECTED`. stage 기록은 건강 snapshot 성공과 초기 `ai_response` 실패만 존재하며 최종 장소 검증·경로·저장 단계 기록 없음. 이전 P2-4C의 경로 실패와 다른 위치의 실패.

해당 두 실행의 1차 구조화 검증 경고: `tour:2762860`, `교동쌈밥 한정식 (A, B, C)` 메뉴 원본 불일치. 기존 correction 후에도 최종 거부. 강릉 repeat 1·2에도 `tour:623279` 메뉴 불일치 경고가 있으나 최종 생성 성공. 처음부터 검증 오류가 없었다는 의미와 최종 성공을 구분.

거부된 AI 선택 메뉴와 해당 요청의 firstmenu·treatmenu 원문은 보존 raw에 없음. 정확한 잘못된 선택과 원문 분해 오류의 구분은 미확정. 현재 쉼표 구분자는 괄호 안 쉼표도 분할하므로 `교동쌈밥 한정식 (A,B,C)`라는 합성 입력은 세 조각으로 분리. 이는 오프라인으로 확인한 parser 위험이며 실제 실패 원인의 확정 증거는 아님. `·`로 연결된 메뉴의 해석도 별도 검토 대상. 이번 측정 후 운영 코드·단언 완화 없이 결과 보존.

서울 repeat 1의 둘째 날 `가야밀냉면해물칼국수` / `해물손칼국수`에서 `해물` 키워드 적중. 실제 새우 포함 여부는 미확인. proxy 적중을 삭제하거나 재료 안전성이 검증된 것으로 변경하지 않는 판정.

새 Java 계약은 성공 상세의 ID·유형과 firstmenu·treatmenu에서 분리한 메뉴의 정확 일치 검사. 기존 측정기의 양방향 부분 문자열 일치율 60/60은 그 계약의 독립 재증명이 아님. 원본 상세가 없어 raw만으로 strict 출처를 재계수할 수 없는 한계. 또한 메뉴 출처 일치는 실제 재료·영양 정확성·영업 여부의 증명이 아님.

복약 검사는 점심 종료 30분 후, 기존 비식사 슬롯 충돌 이동, 10분 체류, 동일 시각 동행인 복약 설명 병합·MEDICATION_SCHEDULE 태그·장소 필드 부재의 fixture 계약 확인. raw `saved=false`는 사용자 확정 전 상태이며 DB 미저장 의미가 아님. 성공 10회 persistence stage 성공 기록과 원자성 회귀 테스트는 존재하나 이번 배치의 DB 행 전체 독립 감사는 미실행.

### 채택 판정과 다음 조사

**이번 배치 채택 보류. Draft PR #178 유지, dev 미병합, main sync 없음.** 통과 수 10/12는 R0보다 2건 감소하여 계획상 추가 12회 표본이 필요한 구간. 추가 실행은 별도 비용 승인 전 금지. 지정 장소 포함 기준 11회 미달과 알레르기 proxy 0건 조건도 미충족. 이 배치로 품질 개선 또는 최종 통계적 기각을 확정하지 않는 판정.
