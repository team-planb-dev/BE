### 1-5. 범위와 알려진 한계

- gate 범위는 새로 선택한 식사. 편집에서 그대로 보존하는 저장 슬롯(`verifyUnchanged`, 날짜 재구성의 보존 날짜)은 검사하지 않음. 알레르기 등록 전에 저장한 일정도 편집할 수 있도록 하기 위한 범위
- AVOID(피하는 음식)는 Java 제외 대상이 아니며 프롬프트 지시만 적용. `ALLERGY_CHECK` 태그는 AVOID만 있는 여행자에게도 계속 부여
- 분류어 사전은 새우·게·갑각류 3개 항목. 다른 알레르기와 영문 등록명(`shrimp`)은 등록 이름 자체만 판정
- 한 글자 등록명은 보수 판정이라 `가게` 같은 업소 표기도 제외되는 알려진 오탐(안전 우선)
- `validateCompletedMeals`의 검사는 보충 단계 필터 뒤의 이중 방어이며 단독 테스트 없음
- 위반 사유 문구(알레르기 단어·업소명·메뉴명, 여행자 이름 없음)는 재선택 프롬프트, 날짜 재구성 WARN 로그, 오류 메시지에 남음
- 후보 감소로 필수 식사를 채우지 못하면 `INVALID_AI_PLACE` 증가 가능(합의한 교환관계). 실제 증감은 7단계 측정
